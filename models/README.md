# Trained model

Place the trained model here as:

```
models/ecg_efficientnetb0.keras
```

Two ways to get it:

1. **Train it** with `notebooks/cardiolens_training.ipynb` (about 20 minutes on a Kaggle T4 GPU) and download `ecg_efficientnetb0.keras` from the notebook output.
2. **Download it** from this repository's [Releases](../../releases) page, if a release is available.

The file is about 60 MB (it includes the optimizer state), so it is distributed through Releases rather than committed to the repository.
